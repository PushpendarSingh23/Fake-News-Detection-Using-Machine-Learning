Core Architecture & Capabilities

Deterministic NLP Pipeline
Cleans raw unstructured text by stripping URLs, HTML artifacts, and publisher provenance metadata (e.g., Reuters wire tags) before stopword filtering and WordNet lemmatization.
Multi-Model Engine
Engineered for side-by-side comparative classification utilizing Logistic Regression, Random Forest Ensembles, and Platt-scaled Support Vector Classifiers (SVC).
Calibrated Confidence
Computes continuous probability distributions across REAL and FAKE categories, preventing overconfident binary decisions and providing clear statistical estimates.
Enterprise Hardening
Features CSRF protection, sliding-window rate limiting, HTTPOnly session cookies, transparent password rehashing (PBKDF2 to Bcrypt), and idempotent database migrations.

End-to-End Detection Pipeline

How user text flows through the natural language processing and statistical machine learning pipeline:

Step 01
Ingestion & Sanitization
Text validation, URL/HTML tag stripping, and publisher header detachment.
Step 02
NLP Normalization
Lowercasing, punctuation scrubbing, NLTK stopword pruning, and morphological lemmatization.
Step 03
TF-IDF Vectorization
Term frequency-inverse document frequency mapping into high-dimensional n-gram feature space.
Step 04
Model Inference & Audit
Classification, probability calibration, UI rendering, and MySQL history audit trail.
